# X 单向关注筛选器

一个不依赖构建工具的 Chrome MV3 扩展原型，用来筛选：你关注了，但没有关注你的 X 账号。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 登录 [x.com](https://x.com)，点击浏览器工具栏中的扩展图标，再点击“开始扫描”。

## 工作方式

- 扩展读取当前登录账号的 Following 和 Followers 页面中的公开用户卡片。
- 自动滚动列表，完成两边集合的比对。
- 结果显示在 X 页面右上角浮层，可导出 CSV。
- 账号列表与扫描状态只保存在浏览器的 `chrome.storage.local` 中。
- 扩展不调用 X 私有 API、不自动取消关注、不上传账号列表。

## 已知限制

- X 的页面结构可能变化；如果 X 改动 `UserCell` 标记，需要更新选择器。
- 必须登录 X，并允许扩展访问 `x.com`。
- 列表加载受 X 自身限流、网络和账号权限影响；扫描过程中请保持标签页打开。
- 当前版本只支持 Chrome/Chromium 的桌面扩展加载方式。
